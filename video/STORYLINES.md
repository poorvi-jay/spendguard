Picked: **A — The listing that lied.** The other two are kept so a later turn can switch.

## A — The listing that lied (built)

Device: one object across apps (a poisoned product listing). Form: object-to-object chain.
A product listing carries a hidden note telling AI agents to buy it. The agent falls for it, the
payment is authorized in PayPal, and SpendGuard catches it against the pinned request and voids it.
Then quick proof (a nudge, a blocked category), the ledger, 21/21, the claim.

- First 2 s: the real `moist-04` listing text fills the frame; its hidden note is struck through
  with a lime marker.
- Beats: hook (listing) → tension (agent buys it, Approve in PayPal) → reveal (SpendGuard) →
  proof (blocked + void; nudge; category block) → payoff (21/21) → claim → end card.
- Look: the product's own site: #f4f5ef grid ground, #11130f ink, #d9f56b lime, Manrope + IBM Plex Mono.
- Sound: silent (no music source without a HeyGen sign-in); add a track later.

## B — The unchecked wallet

Device: life before and after. Form: split screen to one.
Left, an agent with a bare card buys the wrong moisturiser, the $329 headphones and the wine while the
budget meter drains red. Right, the same requests through SpendGuard: approved, nudged, blocked. The
split collapses into SpendGuard.

## C — Type carries the argument

Device: type carries the argument. Form: cut on the beat.
Giant kinetic Manrope on ink and lime fields: "Your agent has your card." "It read a product page."
"The page lied." Each line punches into a real SpendGuard moment, ending on 21/21 landing huge.
